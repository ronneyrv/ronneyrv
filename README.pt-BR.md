# Projeto Principal

## Finance Family

### Plataforma Full Stack de Gestão Financeira Orientada a Produção

O Finance Family é meu principal projeto de portfólio e a demonstração mais completa das minhas habilidades atuais em engenharia de software.

É uma plataforma full-stack para gerenciamento financeiro pessoal e familiar, desenvolvida com forte foco em modelagem de domínio, segurança, testes, infraestrutura, segurança de deploy e manutenibilidade.

### Backend

[Finance Family API](https://github.com/ronneyrv/finance-family-api)

Desenvolvido com Java 21, Spring Boot, Spring Security, JWT, PostgreSQL, JPA/Hibernate, Flyway, Gradle, Docker, Testcontainers e GitHub Actions.

### Frontend

[Finance Family Web](https://github.com/ronneyrv/finance-family-web)

Desenvolvido com React, TypeScript, Vite, Tailwind CSS, Axios, Recharts, Vitest, React Testing Library e Vercel.

### Principais funcionalidades

- Autenticação e autorização de usuários
- Gerenciamento de contas financeiras
- Receitas e despesas
- Categorias e subcategorias
- Gerenciamento de cartões de crédito
- Compras e parcelas de cartão
- Gerenciamento e pagamento de faturas
- Transações recorrentes
- Transferências internas entre contas financeiras
- Dashboards financeiros
- Análise de saúde financeira
- Análise de comprometimento da renda
- Análises financeiras por categoria
- Indicadores financeiros mensais e anuais
- Interface web responsiva

### Práticas de engenharia
